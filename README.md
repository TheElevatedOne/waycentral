## Usage

```
> waycentral [-h/--help] [OPTIONS]

Centralized Program for Waybar Modules

HELP:
  -h, --help    Show this help message
  -v, --version Show version
  Defaults are MY preferences (shown with a *).

OPTIONS:
  -c, --clock [24H, 12AP, 12H*]
                Print Waybar JSON for clock.
                24H -> 24 Hour clock;
                12AP -> 12 Hour clock with AM/PM;
                12H -> 12 Hour clock without AM/PM.
  -d, --date [DMY, MDY, YMD*] [M*, S]
                Print Waybar JSON for date.
                DMY -> Day/Month/Year;
                MDY -> Month/Day/Year;
                YMD -> Year/Month/Day.
                M -> Monday First in Calendar Tooltip;
                S -> Sunday First in Calendar Tooltip.
  -d, --date [next, prev, today]
                Change the month of the calendar tooltip
                of the running date modules.
  -b, --battery Print Waybar JSON for battery.
  -s, --sysmon [CPU, MEM, NET, GPU [N (0*)]]
                Print Waybar JSON for system
                monitoring.
                CPU -> CPU Utilization;
                MEM -> RAM Usage;
                NET -> Network Usage;
                GPU -> GPU Usage of GPU N, all GPUs
                       in the tooltip.
  -k, --keys [CAPS, NUM, SCROLL]
                Print Waybar JSON class for each
                lock key.
                CAPS -> Caps Lock
                NUM -> Num Lock
                SCROLL -> Scroll Lock
  -a, --hotspot Print Waybar JSON for hotspot using
                "create_ap". (ex. linux-wifi-hotspot)
  -u, --updates [MINUTES (30*)] [NOAUR]
                Print Waybar JSON for pacman and AUR
                updates. Checks every MINUTES and
                after every pacman transaction.
                NOAUR -> Do not check the AUR.
  -u, --updates check
                Make the running modules check now.
  -V, --volume [OUT*, IN]
                Print Waybar JSON for the default
                output (speakers/headphones) or
                input (microphone) device.
  -V, --volume [OUT*, IN] [up, down] [STEP (5*)]
  -V, --volume [OUT*, IN] [set] [PERCENT]
  -V, --volume [OUT*, IN] [mute, unmute, toggle, next]
                Change the volume, mute, or switch
                to the next device.
  -n, --network Print Waybar JSON for the network
                connection (NetworkManager).
  -l, --layout  Print Waybar JSON for the Hyprland
                layout of the active workspace.
  -m, --music [PLAYER[:BINARY]] [LENGTH (40*)]
                Print Waybar JSON for the MPRIS player.
                PLAYER -> Player to follow (ex. fooyin),
                          otherwise the one playing.
                BINARY -> Program to start for PLAYER,
                          if it is not the same name.
                LENGTH -> Maximum length of the text.
  -m, --music [PLAYER[:BINARY]] [toggle, play, pause, stop,
              next, prev, raise]
                Control the player. toggle, play and
                raise start PLAYER when not running.
```

## Installation

### AUR

This package is on the Arch User Repository.

Install either [waycentral-git](https://aur.archlinux.org/packages/waycentral-git) or [waycentral-bin](https://aur.archlinux.org/packages/waycentral-bin).

### Release

Download and extract the `.tar.gz` from the [latest release](https://github.com/TheElevatedOne/waycentral/releases/latest).
Place `waycentral` binary somewhere on `$PATH`.

### Building

**Requirements:**

- gcc, make, pkgconf
- glibc
- pacman (libalpm), curl, json-c - updates module
- libpulse - volume module (works with PipeWire)
- systemd-libs (sd-bus) - network and music modules
- gtk3 - systray module

1. Clone the repository

- ```
  git clone https://github.com/TheElevatedOne/waycentral.git
  cd waycentral
  ```

2. Build the binaries

- ```
  make release
  sudo make install # to /usr; or make install to ~/.local
  # Packagers: make install PREFIX=/usr DESTDIR="$pkgdir"

  # Uninstalling
  # sudo make uninstall  or  make uninstall
  ```

## Options

### Clock

- Shows clock, Uptime and Time Since Root Birth / System Install

- 24H:
  - Prints a clock JSON in 24 hour / military time format
  - `{"text":"23:10:18","tooltip":"Uptime:\t1 day/s 04:33:15\nBirth:\t99 day/s"}`
- 12AP:
  - Prints a clock JSON in 12 hour format with AM/PM
  - `{"text":"11:12:24 PM","tooltip":"Uptime:\t1 day/s 04:35:20\nBirth:\t99 day/s"}`
- 12H:
  - Prints a clock JSON in 12 hour format without AM/PM
  - `{"text":"11:13:23","tooltip":"Uptime:\t1 day/s 04:36:19\nBirth:\t99 day/s"}`
  - This one is the default, as I use it as main

**Example Module:**

```json
"custom/clock": {
  "format": "{text}",
  "restart-interval": 1,
  "exec": "waycentral -c",
  "return-type": "json"
}
```

### Date

- Shows the date and calendar similar to the `cal` command

- DMY:
  - Sets the date to Day/Month/Year format
- MDY:
  - Sets the date to Month/Day/Year format
- YMD:
  - Sets the date to Year/Month/Date format

- M:
  - Sets the calendar start day to Monday
- S:
  - Sets the calendar start day to Sunday

**Example Module:**

```json
"custom/date": {
  "format": "{text}",
  "restart-interval": 1,
  "exec": "waycentral -d",
  "return-type": "json"
}
```

The tooltip is a monospace calendar with ISO week numbers, the days of the neighbouring
months faded, weekends dimmed and today underlined, followed by the full date.

Scrolling changes the month (it goes back to the current one 2 minutes after the last scroll):

```json
"custom/date": {
  "format": "{text}",
  "exec": "waycentral -d",
  "return-type": "json",
  "on-scroll-up": "waycentral -d prev",
  "on-scroll-down": "waycentral -d next",
  "on-click-middle": "waycentral -d today"
}
```

### Battery

Shows battery information, stats, health, etc.

Requires NerdFonts to be used as the text has an icon in it.

**Result:**

{"text":"80% 󰂁","tooltip":"<b>BAT1:</b>\tA32-K55\nManufact:\tASUS \nTech:\tLi-ion\nStatus:\tNot charging\nCharge:\t80%\nHealth:\t100%\nVoltage:\t11.9 V\nCurrent:\t0.0 A\nCharging:\t0.0 W"}
```

**Example Module:**

```json
"custom/battery": {
  "format": "{text}",
  "restart-interval": 1,
  "exec": "waycentral -b",
  "return-type": "json"
}
```

### Sysmon

#### CPU

Prints CPU Utilization averaged and per-core in tooltip. Dynamic, changes per core count.

**Example Module:**

```json
"custom/cpu-monitor": {
  "format": "{text}  ",
  "restart-interval": 1,
  "exec": "waycentral -s CPU",
  "return-type": "json"
}
```

**Result:**

```json
{"text":"4%","tooltip":"CPU0: 5%\nCPU1: 3%\nCPU2: 2%\nCPU3: 3%\nCPU4: 4%\nCPU5: 6%\nCPU6: 3%\nCPU7: 4%"}
```

#### MEM

Prints Memory Utilization and breaks it down in tooltip, also shows Swap.

**Example Module:**

```json
"custom/mem-monitor": {
  "format": "{text}  ",
  "restart-interval": 1,
  "exec": "waycentral -s MEM",
  "return-type": "json"
}
```

**Result:**

```json
{"text":"18%","tooltip":"Total RAM: 39.0 GiB\nUsed RAM: 7.1 GiB (18.2%)\nFree RAM: 14.8 GiB (37.9%)\nAvailable RAM: 32.0 GiB (81.9%)\nBuffered RAM: 466.1 MiB (1.2%)\nCached RAM: 16.7 GiB (42.7%)\nShared RAM: 466.1 MiB (1.2%)\n\nTotal Swap: 8.0 GiB\nUsed Swap 0.0 kiB (0.0%)\nFree Swap: 8.0 GiB (100.0%)"}
```

#### NET

Prints Current Internet Speed/Usage (Sum of Upload and Download). In tooltip shows separate values and total upload/download since system startup.

**Example Module:**

```json
"custom/net-monitor": {
  "format": "{text} 󰛳 ",
  "restart-interval": 1,
  "exec": "waycentral -s NET",
  "return-type": "json"
}
```

**Result:**

```json
{"text":"2 kiB/s","tooltip":" 2 kiB/s [9.33 GiB]\n 66 B/s [8.22 GiB]"}
```

#### GPU

Prints the GPU usage (averaged over a second) of GPU `N` (default `0`, the first card), and
every GPU in the tooltip: name, driver, usage, VRAM, temperature, power, core/memory clock and
fan. AMD (`amdgpu`/`radeon`) reports everything through sysfs; Intel and `nouveau` report what
their driver exposes; NVIDIA's proprietary driver is read through NVML when it is installed.

**Example Module:**

```json
"custom/gpu-monitor": {
  "format": "{text} 󰢮 ",
  "exec": "waycentral -s GPU",
  "return-type": "json"
}
```

**Result:**

```json
{"text":"8%","percentage":8,"tooltip":"<b>GPU0:</b>\tEllesmere [Radeon RX 470/480/570/570X/580/580X/590]\nDriver:\tamdgpu\nUsage:\t8%\nVRAM:\t805.9 MiB / 8.0 GiB (9.8%)\nTemp:\t52 °C\nPower:\t16.1 W\nCore:\t1196 MHz\nMem:\t300 MHz\nFan:\t783 RPM (22%)"}
```

### Keys

Prints a class of either "on" or "off". Useful with CSS.

The keyboards are watched for events, so the module updates the moment a lock key changes
(needs read access to `/dev/input/event*`, usually the `input` group).

**Results:**

Either

```json
{"class":"on"}
```

or

```json
{"class":"off"}
```

**Example Modules:**

For Capslock:

```json
"custom/capslock": {
  "format": "A",
  "exec": "waycentral -k CAPS",
  "restart-interval": 1,
  "return-type": "json"
}
```

For Numlock:

```json
"custom/numlock": {
  "format": "9",
  "exec": "waycentral -k NUM",
  "restart-interval": 1,
  "return-type": "json"
}
```

**Example CSS:**

Makes the font thinner when off.

```css
#custom-numlock {
  font-weight: 500;
}
#custom-numlock.off {
  font-weight: 100;
}
```

### Hotspot

Prints a JSON with class, alt (for icons) and hotspot details.

Use with `create_ap`/based tool (ex. [linux-wifi-hotspot](https://github.com/lakinduakash/linux-wifi-hotspot)).

**Results:**

```json
{"class":"off","alt":"off","tooltip":"Hotspot Inactive"}
```

```json
{"class":"on","alt":"on","tooltip":"<b>SSID:</b>\thotspot\n<b>PASS:</b>\t123456\n<b>FREQ:</b>\t2.4 GHz\n<b>DEST:</b>\twlo1\n<b>SRC:</b>\tenp3s0\n<b>HIDE:</b>\tNo"}
```

**Example Module:**

```json
"custom/hotspot": {
  "format": "{icon}",
  "format-icons": {
    "on": "󰀂 ",
    "off": "󰯡 "
  },
  "restart-interval": 1,
  "exec": "waycentral -a",
  "return-type": "json"
}
```

### Updates

Counts available updates for every repository enabled in `/etc/pacman.conf` and for the AUR,
without root: like `checkupdates`, a private copy of the sync databases is kept in
`~/.cache/waycentral/pacman`. Checks every 30 minutes (or `MINUTES`) and again right after
any pacman transaction finishes, so the count drops as soon as you update.

```json
"custom/updates": {
  "format": "{text} 󰮯 ",
  "exec": "waycentral -u 30",
  "return-type": "json",
  "on-click": "waycentral -u check"
}
```

**Result:**

```json
{"text":"12","alt":"updates","class":"updates","tooltip":"<b>Updates:</b>\t12\ncore:\t2\nextra:\t7\nmultilib:\t0\nchaotic-aur:\t1\naur:\t2\n\nChecked:\t14:30"}
```

`class`/`alt` is `updates`, `none` or `error` (offline; cached databases are used).

### Volume

Shows the default output (`OUT`, speakers/headphones) or input (`IN`, microphone) device of
PulseAudio/PipeWire. Updates instantly on any volume, mute or device change.

`alt` is the kind of device (`speaker`, `headphones`, `headset`, `microphone`, `hdmi`),
with `-muted` appended when muted, so icons can follow the device:

```json
"custom/volume": {
  "format": "{text} {icon}",
  "format-icons": {
    "speaker": "󰕾", "speaker-muted": "󰖁",
    "headphones": "󰋋", "headphones-muted": "󰟎",
    "headset": "󰋎", "headset-muted": "󰋐",
    "hdmi": "󰡁", "hdmi-muted": "󰖁"
  },
  "exec": "waycentral -V OUT",
  "return-type": "json",
  "on-click": "waycentral -V OUT toggle",
  "on-click-right": "waycentral -V OUT next",
  "on-scroll-up": "waycentral -V OUT up 5",
  "on-scroll-down": "waycentral -V OUT down 5"
},
"custom/mic": {
  "format": "{text} {icon}",
  "format-icons": { "microphone": "󰍬", "microphone-muted": "󰍭", "headset": "󰋎", "headset-muted": "󰋐" },
  "exec": "waycentral -V IN",
  "return-type": "json",
  "on-click": "waycentral -V IN toggle",
  "on-scroll-up": "waycentral -V IN up 5",
  "on-scroll-down": "waycentral -V IN down 5"
}
```

`next` makes the next device the default, e.g. to switch between speakers and headphones.

### Network

Shows the current connection from NetworkManager (falls back to the kernel's default route
without it). Updates instantly on connection changes and every 5 s for the wifi signal.

`alt`/`class` is `wifi`, `ethernet`, `vpn`, `other`, `disconnected` or `disabled`,
`percentage` is the wifi signal.

```json
"custom/network": {
  "format": "{icon}",
  "format-icons": {
    "wifi": "󰖩 ", "ethernet": " ", "vpn": "󰖂 ", "other": "󰛳 ",
    "disconnected": "󰖪 ", "disabled": "󰲛 "
  },
  "exec": "waycentral -n",
  "return-type": "json",
  "on-click": "kitty --class nmtui nmtui"
}
```

**Result:**

```json
{"text":"MyWifi","alt":"wifi","class":"wifi","percentage":78,"tooltip":"<b>Connection:</b>\tMyWifi\n<b>Interface:</b>\twlan0\n<b>SSID:</b>\tMyWifi\n<b>Signal:</b>\t78%\n<b>Freq:</b>\t5.2 GHz\n<b>Speed:</b>\t866 Mbit/s\n<b>IPv4:</b>\t192.168.1.20/24\n<b>Gateway:</b>\t192.168.1.1"}
```

### Layout

Shows the Hyprland layout of the active workspace (per workspace layouts included) over
Hyprland's IPC socket, no `hyprctl`/`jq` needed. `text` is `D` (Dwindle), `M` (Master),
`S` (Scrolling), `Mo` (Monocle), or the first letter of any other (plugin) layout;
`alt`/`class` is the layout's name.

```json
"custom/hyprlayout": {
  "format": "[{text}]",
  "exec": "waycentral -l",
  "return-type": "json"
}
```

### Music

Shows and controls MPRIS players over D-Bus directly (no `playerctl` needed). Without a
`PLAYER` it follows the player that is playing; with one (e.g. `fooyin`, `spotify`) only that
player. `toggle`, `play` and `raise` start the player when it is not running; use
`PLAYER:BINARY` when the program is called differently (e.g. `spotify:spotify-launcher`).

`alt`/`class` is `playing`, `paused`, `stopped` or `none`.

```json
"custom/music": {
  "format": "{icon} {text}",
  "format-icons": { "playing": "󰎇", "paused": "󰏤", "stopped": "󰓛", "none": "󰎊" },
  "exec": "waycentral -m fooyin 40",
  "return-type": "json",
  "on-click": "waycentral -m fooyin toggle",
  "on-click-right": "waycentral -m fooyin raise",
  "on-scroll-up": "waycentral -m fooyin prev",
  "on-scroll-down": "waycentral -m fooyin next"
}
```

## Systray

`waycentral-tray.so` is a system tray loaded by Waybar as a CFFI module, a replacement for the
built-in `tray`:

- Icons come from your GTK icon theme, preferring `-symbolic` variants that are recoloured with
  the theme's foreground colour (follows pywal/theme reloads), falling back to the app's own
  icon.
- Right-click menus are built from the app's menu every time they open (no stale menus).
- Provides the `StatusNotifierWatcher` itself, so it works without the built-in tray.

```json
"cffi/tray": {
  "module_path": "/usr/lib/waycentral/waycentral-tray.so",
  "icon-size": 16,
  "spacing": 8,
  "prefer-symbolic": true,
  "show-passive": false
}
```

Left click activates the app (or opens its menu if it only has one), middle click is the
secondary action, right click opens the menu, scrolling is passed to the app. Style with the
`.tray`, `.item`, `.passive` and `.needs-attention` CSS classes.

## Library

Everything waycentral does is also available as a C library, `libwaycentral`,
with the public header [`waycentral.h`](waycentral.h). `make install` (and the AUR packages)
install the binary, `libwaycentral.so`, `libwaycentral.a`, the header and a `pkg-config` file.

- `wc_*_get` / `wc_*_list` fill plain structs with the raw values (CPU, memory, network,
  batteries, lock keys, hotspot, calendar grid, uptime).
- `wc_*_json` return the same Waybar JSON line the binary prints. Free it with `free()`.
- `wc_*_watch` block and call a callback with every new JSON line (event driven modules).
- `wc_audio_control`, `wc_music_control` and `wc_music_launch` control devices and players.

```c
#include <stdio.h>
#include <stdlib.h>
#include <waycentral.h>

int main(void) {
  struct wc_meminfo mem;
  if (wc_meminfo_get(&mem) == 0)
    printf("RAM used: %llu kiB\n", mem.mem_used);

  char *json = wc_clock_json(WC_CLOCK_24H);
  if (json) {
    puts(json);
    free(json);
  }
  return 0;
}
```

```
cc example.c $(pkg-config --cflags --libs waycentral) -o example
```
